Welcome to my collection of Python games built using the Pygame library. Each project showcases different aspects of game development — from simple mechanics to player-vs-player battles and AI logic. Feel free to explore, run, and modify these games!

📁 Projects Included
🐦 Flappy Bird Clone (flappybird.py)
A Python version of the classic Flappy Bird.
Features:


Gravity-based jumping
Scrolling background
Score tracking


🏓 Multiplayer Ping Pong (multipong.py)
A 2-player pong game. Use keyboard controls to play against a friend.
Features:


Two-player support
Real-time ball bouncing and paddle movement
Score system


🔫 Shooter Game (shooter.py)
A simple shooting game prototype.
Features:


Player movement and shooting
Bullet animation
Collision detection
